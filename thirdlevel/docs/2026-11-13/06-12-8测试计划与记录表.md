## 2. 功能用例

> 判定标准：预期与“验收口径”一致；风险样例应出现“存在风险”，正常样例不应误报；出错必须有明确状态，**不得显示“无风险”**。

| 编号 | 用例 | 前置/操作 | 预期结果 | 实际结果 | 结论 | 证据 |
| --- | --- | --- | --- | --- | --- | --- |
| F01 | 首次启动检测 | App → 第三级 → 填地址/令牌 → 授悬浮窗 → 开始 → 允许屏幕共享 | 悬浮窗出现，状态“检测中”，/health 预检通过 | | | |
| F02 | 停止检测 | 悬浮窗「停止」/ App 内停止 | 悬浮窗消失、前台服务停止、通知移除、无残留请求 | | | |
| F03 | 风险画面（转账页） | 展示 02_风险画面（网页/图片/会议白板） | 6-10 秒内出现红色「存在风险」+ 风险等级/证据/原因 | | | |
| F04 | 普通画面 | 展示 01_普通画面/普通会议界面 | 绿色「无风险」，显示画面汇总 | | | |
| F05 | 风险→正常切换 | F03 后切 F04 | 连续 2 次无风险后清除红色提示（首次切换仍暂保留，属设计行为） | | | |
| F06 | 应用音频（若可采集） | 勾选音频，播放 04_风险语音 | 约 10-20 秒内出现语音风险提示，标题「存在风险」 | | | |
| F07 | 音频不可采集场景 | 目标应用禁止 AudioPlaybackCapture | 明确显示「语音：采集不可用」，不影响画面链路，不误报无风险 | | | |
| F08 | 画面+语音组合 | 风险画面 + 风险语音 | 两路证据分别展示，标题「存在风险」 | | | |
| F09 | 重复提示抑制 | 风险画面保持 15 秒不动 | 不重复弹窗/刷屏；风险状态保持 | | | |
| F10 | 服务端断开 | 停止 Node 服务后继续检测 | 橙色「检测受限」+「分析失败/无法连接」；已有风险不清除；不显示“无风险” | | | |

## 3. 异常/边界用例

| 编号 | 场景 | 操作 | 预期结果 | 实际结果 | 结论 | 证据 |
| --- | --- | --- | --- | --- | --- | --- |
| E01 | 黑屏/受保护画面 | 打开 `FLAG_SECURE` 页面/DRM 视频/受保护会议画面 | 橙色「检测受限」+“黑屏或受保护画面”，**不显示无风险**，不发送新风险请求 | | | |
| E02 | 空白/纯色画面 | 打开纯白加载页/纯色占位页 | 「检测受限」+“空白或纯色画面，未采集到可分析内容” | | | |
| E03 | 瞬态黑帧 | 普通画面快速切换应用/旋转 | 不应频繁闪“检测受限”（连续 2 帧才进入受限） | | | |
| E04 | 屏幕共享授权撤销 | 系统通知栏/系统弹窗停止共享 | 状态区显示“屏幕共享授权已撤销，请重新授权后开启检测”，服务清理 | | | |
| E05 | 悬浮窗权限撤销 | 系统设置中关闭“显示在其他应用上层” | 状态明确提示“悬浮窗权限已撤销”，不崩溃 | | | |
| E06 | 错误服务地址/未启动 | 填错地址或服务未启动 → 开始 | 开始前健康检查失败，提示“无法连接风险分析服务…”，按钮恢复可用 | | | |
| E07 | 错误令牌 | 填错令牌 | 401 → 明确认证失败提示，不显示无风险 | | | |
| E08 | 网络中断 | 检测中关 Wi-Fi/移出局域网 | 「分析失败/网络错误」+ 自动重试 1 次（同 request_id） | | | |
| E09 | 服务端超时/5xx | 临时断上游/调小超时 | 504/503 错误提示，保留已有风险；客户端重试 1 次 | | | |
| E10 | 横竖屏切换 | 检测中旋转屏幕 | 当前版本约定：停止后重新开启；记录实际表现 | | | |
| E11 | 锁屏/后台 | 检测中锁屏/切后台 | 前台服务与通知保持；恢复后继续（记录实际表现） | | | |
| E12 | 空 OCR 内容 | 纯图标/无文字页面 | 不崩溃、不误报；按画面视觉分析结果展示 | | | |
