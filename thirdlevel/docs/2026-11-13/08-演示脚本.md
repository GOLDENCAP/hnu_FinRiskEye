# 第三级演示脚本（12/15 交付用）

> 目的：用 8-10 分钟稳定演示“授权 → 画面/音频采集 → 分析 → 悬浮窗提示”，覆盖正常与风险样例，并说明已知限制。  
> 前提：已按 `README.md` 完成服务端启动与平板安装；演示前 10 分钟做一次预检。

## 0. 演示前预检（10 分钟）

1. 电脑启动风险服务：`cd thirdlevel\server; npm start`（或 `.\start-local.ps1`），确认 `GET /health` 返回 ok；
2. 电脑查本机局域网 IP（`ipconfig`），确认与平板同一 Wi-Fi；防火墙放行 TCP 3100：
   `New-NetFirewallRule -DisplayName "FinRiskEye 3100" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 3100 -Profile Private,Domain`；
3. 平板安装最新 APK（`ARTIFACTS/app-debug-thirdlevel-*.apk`），打开 App 确认能进入第三级页面；
4. 平板先把测试素材放到本地相册/文件：`01_普通画面.png`、`02_风险画面.png`、`04_风险语音_冒充公安.wav`；
5. 准备录屏（平板系统录屏 + 电脑端服务日志窗口），用于记录延迟；
6. 关闭平板的免打扰/自动锁屏，电量 > 50%。

## 1. 演示流程（约 8 分钟）

| 步骤 | 操作 | 讲解要点 | 预期画面 |
| --- | --- | --- | --- |
| 1 | 展示 App 主界面，说明一/二/三级能力边界 | 一级本地视频、二级 WebRTC 会议、三级跨应用（本演示）、四级规划 | 主页「第三级：跨应用风险检测」按钮 |
| 2 | 进入第三级页，填写服务地址与令牌 | 服务地址是自建风险服务（密钥只在服务端，APK 不含 Key） | 页面表单 |
| 3 | 点「授予悬浮窗权限」并允许 | 悬浮窗用于常驻显示检测状态与风险提示 | 系统权限页 → 返回 |
| 4 | 点「开始跨应用风险检测」→ 系统屏幕共享弹窗点允许 | 强调“用户主动授权、可随时停止”；说明受保护画面会显示黑屏→检测受限 | 右上角悬浮窗出现「检测中」 |
| 5 | 展示 `01_普通画面`（普通会议内容） | 正常内容不应误报 | 悬浮窗绿色「无风险」，显示“画面：未发现风险” |
| 6 | 切到 `02_风险画面`（伪造转账页：安全账户、洗钱、不要告诉任何人） | 说明触发点：要求转账到“安全账户”、冒充公检法、要求保密 | 约 2-6 秒后红色「存在风险」+ 风险等级/证据/原因 |
| 7 | 回到普通画面 | 说明“连续两次无风险才清除”的防抖动设计 | 红色提示保持 1 次后变绿「无风险」 |
| 8 | （可选，若音频可采集）勾选音频，播放 `04_风险语音` | 说明 AudioPlaybackCapture 只在目标应用允许时可用；不可用会显示“语音采集不可用” | 约 10-20 秒后语音证据出现 |
| 9 | 打开受保护页面（或说明 `FLAG_SECURE` 场景） | 说明黑屏是系统限制，不是识别失败；显示橙色「检测受限」而非“无风险” | 橙色「检测受限」+说明 |
| 10 | 点悬浮窗「停止」 | 说明通知/前台服务/授权均结束，隐私边界 | 悬浮窗消失、通知移除 |

## 2. 失败兜底

| 万一 | 处理 |
| --- | --- |
| 服务连不上 | 检查电脑 IP/防火墙/服务窗口；用浏览器访问 `http://<IP>:3100/health`；重启服务 |
| 视觉结果波动（先 none 后 high） | 保持风险画面 2-3 个采样周期（约 4-6 秒）再判断；说明客户端有连续两次无风险才清除的兜底 |
| 模型超时（橙色检测受限） | 说明网络/上游波动，稍等重试；客户端会沿用同一 request_id 重试一次 |
| 平板音频采集不可用 | 属预期限制（腾讯会议可能禁止），展示“语音采集不可用”提示并说明画面链路不受影响 |
| 悬浮窗权限被系统回收 | 重新授予悬浮窗权限后再开始 |

## 3. 演示话术要点（可直接使用）

- “第三级不是读取 WindowManager，而是用户授权后由系统 MediaProjection 提供屏幕画面，属于合规采集。”
- “截图只在内存中降采样，不保存原图；API Key 只在服务端，APK 里没有。”
- “分析失败时明确显示‘检测受限/分析失败’，不会把失败当成无风险。”
- “受 `FLAG_SECURE`/DRM 保护的画面系统不允许采集，我们显示‘检测受限’并提示原因。”
- “当前为教学演示版本：局域网 HTTP + 测试令牌，正式部署建议 HTTPS + 随机令牌 + 访问控制。”
