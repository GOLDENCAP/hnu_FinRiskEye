## 1. 用户反馈问题（已修复）

**现象**：打开 App 后，最上面一行（"Room Name" 上面的 "Server Address" 输入框）被顶部标题栏
"FinRiskEye 风险检测"遮挡。

**原因**：工程 `targetSdk = 36`，Android 15/16 强制 edge-to-edge 绘制；旧版 MaterialComponents
ActionBar 不会为内容补系统栏 padding，导致标题栏与首行内容重叠。

**修复**：
1. 新增 `EdgeToEdgeInsets` 工具（Android 15+ 给根布局补 systemBars padding；Android 15 以下保持原行为，不影响平板 Android 12）；
2. `MainActivity` / `ThirdLevelActivity` / `ThirdLevelDemoActivity` 改为无 ActionBar 主题，页面自绘标题；
3. 真机对比截图：`before-fix-main.png`（遮挡）→ `after-fix-main.png`（完整显示）。

## 2. 真机联调中额外发现并修复的问题

| 问题 | 修复 |
| --- | --- |
| 悬浮窗固定 420dp，在 400dp 宽手机上超出屏幕被裁切 | 按 `min(420dp, 屏幕宽-32dp)` 自适应（实测 `width=1104px`） |
| 启动瞬间把系统“屏幕共享”授权弹窗文案（含“密码/泄露”）误判为高风险 | 会话启动后首帧延迟一个采样周期（约 2s）再分析 |
| 状态栏“屏幕共享中”提示被视觉模型误判为风险 | 分析前裁掉状态栏/导航栏，只分析目标应用内容区 |
| 检测页自动熄屏导致采集黑屏 | 检测页加 `FLAG_KEEP_SCREEN_ON`；同时保留“黑屏→检测受限”的正确提示 |

## 3. 真机端到端验证结论（v1.5 APK）

- 设备：Xiaomi 14（23127PN0CC），Android 16（SDK 36），HyperOS OS3.0.307.0.WNCCNXM；
- 连接方式：USB 连接 + `adb reverse tcp:3100 tcp:3100`，手机以 `http://127.0.0.1:3100` 访问电脑上的风险服务（不依赖同一 Wi-Fi）；
- 结果：
  - 开始检测 → 悬浮窗“检测中”，首次分析「无风险」（不再误报系统弹窗/状态栏）；
  - 切内置“风险转账页” → 3–4 秒内出现「存在风险/高风险」，证据为转账页“洗钱案件资金核查…不要告诉任何人…”文案，单次分析 1.5s；
  - 切“普通画面” → 恢复「无风险」；
  - 统计行正常：“最近分析：刚刚，耗时 1.5s｜本次会话：分析 3 次，风险 1 次”；
  - 停止检测 → 服务/悬浮窗/通知均正常结束；
  - 屏幕短暂熄灭时正确显示「检测受限 / 黑屏或受保护画面」，恢复后自动回到「无风险」（单帧黑屏被迟滞忽略）。

## 5. 应用播放音频链路真机验证（补充，已完成）

- 方法：电脑起本地 HTTP 服务（8001）提供 `play.html` + `04_风险语音_冒充公安.wav`；手机 `adb reverse tcp:8001 tcp:8001` 后用内置浏览器打开 `http://127.0.0.1:8001/play.html` 播放；第三级勾选“同时采集应用播放音频”并开始检测、共享整个屏幕；浏览器保持前台播放。
- 结果（真机 logcat + 服务端日志）：
  - `ThirdLevelAudio: application playback capture started`；
  - `audio risk result: high, latencyMs=17942` → 悬浮窗「存在风险」+ 语音分析“你好，我是公安局的，你的银行卡涉嫌…冒充公安机关…典型诈骗开场”；
  - 第二段：`audio risk result: high, latencyMs=9641` → 语音分析“请把钱转到我们的安全账户…冒充公安机关，要求转账到安全账户”；
  - 服务端第一次 audio 请求遇到上游 ASR 瞬时失败返回 503，客户端**沿用同一 request_id 自动重试**，重试返回 200/high（11.9s）；随后片段均正常；
  - 结论：`AudioPlaybackCapture → WAV 分片 → ASR → 风险分析 → 悬浮窗` 链路真机可用；画面与语音风险可同时展示。
  - 注意：MIUI 会对后台播放做音频硬化（后台应用播放会被静音），目标软件需保持前台播放（正常会议场景即前台）。
- 证据：`evidence/device/audio/logcat-audio-e2e.txt`、`audio/server-audio-requests.txt`、`audio/web/play.html`。
