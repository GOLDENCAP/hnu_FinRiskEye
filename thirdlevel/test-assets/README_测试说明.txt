HNU FinRiskEye 第三级测试素材

设备内目录：
/sdcard/Download/FinRiskEyeTest/

文件：
1. 01_普通画面.png
2. 02_风险画面.png
3. 03_普通语音_项目安排.wav
4. 04_风险语音_冒充公安.wav

建议测试顺序：

组合 1：普通画面 + 普通语音
预期标题：无风险
预期分析：画面未发现风险；语音未发现风险

组合 2：风险画面 + 普通语音
预期标题：存在风险
预期分析：画面存在高危转账内容；语音未发现风险

组合 3：普通画面 + 风险语音
预期标题：存在风险
预期分析：画面未发现风险；语音存在冒充公安和转账风险

组合 4：风险画面 + 风险语音
预期标题：存在风险
预期分析：画面和语音均发现风险

操作提示：
1. 在第三级页面勾选“同时采集应用播放音频”。
2. 开始检测并允许屏幕共享。
3. 打开一个 WAV 音频并确认正在播放。
4. 切回对应的 PNG 图片，等待约 10～15 秒。
5. 切换素材前先暂停上一段音频。
6. 风险标题固定为“存在风险”，正常标题固定为“无风险”。
